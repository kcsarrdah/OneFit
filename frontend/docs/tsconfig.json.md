# `tsconfig.json`

## Purpose

TypeScript settings for the app and tests.

## Public API

- `extends: expo/tsconfig.base`
- `compilerOptions.strict: true`
- `paths: { "@/*": ["./*"] }`: `@/components/ui/Button` resolves from the
  `frontend/` root.
- `include`: all `.ts`/`.tsx`, `.expo/types/**/*.ts` (typed routes) and
  `expo-env.d.ts`.

## How it works

Type-check only (`npx tsc --noEmit`); Babel does the compiling. Jest mirrors
the alias in [jest.config](jest.config.md).

## Depends on

`typescript` ~5.8, `expo`.

## Used by

`npx tsc --noEmit`, editors.

## Tests

none.

## Gotchas / TODO

`expo-env.d.ts` and `.expo/types` are generated by `expo start`; on a fresh
checkout `tsc` still passes without them (last run: no errors).
